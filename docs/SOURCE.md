# 来源与文件映射

项目来源为 [maker101io / RobotControlBoard](https://github.com/maker101io/RobotControlBoard)，原项目名称为 “5 in 1 Arduino Robot”。本仓库使用项目资料集合中保存的 `RobotControlBoard-master.zip`，保留其中的五个示例、两张图片、英文 README 与 GPL-3.0 许可证。

[来源校验清单](../source-manifest.json) 包含归档文件摘要、原始成员路径、仓库路径、文件大小和 SHA-256，便于复核。`.gitattributes` 保持文件原始字节，包括换行格式。

2026-10-16 的工程整理增加了中文介绍、引脚与控制逻辑文档、独立 Sketch 目录、来源清单和编译工作流。原始示例代码保持原样。
